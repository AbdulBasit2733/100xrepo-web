# create-100xrepo

A modern, full-stack monorepo template for building scalable applications with Next.js, Express, and more.

## Features

- **Turbo Repo Monorepo**: Efficient monorepo structure for managing multiple packages
- **Frontend**: Next.js with modern setup and optimizations
- **Backend**: Express server for robust HTTP handling
- **WebSocket Server**: Built-in support for real-time communication
- **Database**: PostgreSQL integration with flexible options
- **Package Management**: Uses pnpm for fast and efficient dependency management

## Coming Soon

- React 19 support with latest features
